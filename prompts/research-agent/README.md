# Research agent prompts

These server-only Markdown files are the active instructions for the manager–worker research architecture.

- `SYSTEM.md`: shared research identity and safety principles
- `MANAGER_PLAN.md`: initial task-graph planning
- `MANAGER_REVIEW.md`: convergence and semantic completion judgment
- `WORKER.md`: bounded native tool-loop execution
- `ANSWER.md`: natural cited final synthesis
- `STANDARD.md` and `DEEP.md`: policy differences within one harness
- `FALLBACK.md`: visible degraded manager behavior

Code remains authoritative for schemas, tools, URL policy, citations, budgets, cancellation, and provider routing.

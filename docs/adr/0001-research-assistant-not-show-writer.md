# Build a research assistant, not a show writer

The product is a Nonsense-specific research agent whose minimum quality reference is a general frontier assistant. It may research, explain, organize arguments, and create an outline when asked, but it must not impersonate either host, invent dialogue or jokes, make final editorial choices, or remove the deliberation that improves the show; those boundaries trade maximum automation for trust, host voice, and the creative value of CJ and Jeff's debate.
